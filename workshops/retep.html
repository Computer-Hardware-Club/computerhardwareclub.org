RETEP: The Peter Incident

Run the suspicious installer in your team’s Linux VM, investigate what changed, and get Peter back to normal.

Open workshop terminal

Sign in with your team credentials and run this as your team user.

cd ~/Downloads && ./GTA-VI-Installer.run

Keep the investigation in your team’s VM. AI assistance is off for this workshop. Club officers can help with terminal syntax.

Command reference

Replace uppercase placeholders with values from your VM.

Basics

pwd
Print the current directory.
ls -la
List files, including hidden ones, with details.
cd DIR
Change directories. Use cd ~ to go home.
less FILE
Read a file one screen at a time. Press q to quit.
grep -n 'PATTERN' FILE
Show matching lines and their line numbers.
sudo COMMAND
Run a command with administrator privileges.

Permissions

ls -l FILE
Show permissions, owner, and group.
stat FILE
Show detailed file metadata, including the numeric mode.
id USER
Show a user’s ID and group memberships.
sudo chown OWNER:GROUP FILE
Change the owner and group.
sudo chmod MODE FILE
Change access permissions.

Processes & services

top
Watch live process activity. Press q to quit.
free -h
Show memory usage in readable units.
ps aux
List running processes and their command lines.
systemctl list-units --type=service
List active and failed service units.
systemctl list-unit-files --type=service
List installed service units and their enablement states.
systemctl is-enabled SERVICE
Show a service’s enablement state.
sudo systemctl stop SERVICE
Stop a running service.
sudo systemctl disable SERVICE
Remove a service’s enablement links for automatic startup.

Configuration

systemctl --failed
List failed units.
systemctl status SERVICE
Show a service’s state and recent log messages.
systemctl cat SERVICE
Show the unit definition and any overrides.
sudo journalctl -u SERVICE -n 20 --no-pager
Print the last 20 log entries for a service.
diff -u FILE_A FILE_B
Compare two files and show what differs.
sudo nano FILE
Edit a protected file. Use Ctrl+O to write and Ctrl+X to exit.
sudo systemctl restart SERVICE
Restart a service.

Check your work

check-system

When it prints RESULT: COMPLETE, show a club officer what you found, what you changed, and how you verified the repair.
